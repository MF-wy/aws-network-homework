1. 何謂憑證、HTTPS、HTTP、Port

HTTP

HTTP（HyperText Transfer Protocol，超文字傳輸協定）是瀏覽器與網站伺服器之間傳送資料所使用的通訊協定，預設使用Port 80。

HTTPS

HTTPS（HyperText Transfer Protocol Secure）是在HTTP的基礎上加入TLS加密，可以保護瀏覽器與網站伺服器之間傳輸的資料，預設使用Port 443。

Port

Port（通訊埠）是用來區分同一台電腦上不同網路服務的號碼。

Port 80：HTTP
Port 443：HTTPS
Port 22：SSH

憑證

憑證是HTTPS安全連線的一部分，可以用來確認網站的身分，並協助建立加密的網路連線。

2. Inbound、Outbound防火牆是什麼，怎麼設定

Inbound

Inbound是進入伺服器的網路流量，例如使用者從自己的電腦透過Internet連線到AWS EC2伺服器，就是Inbound。

Outbound

Outbound是從伺服器離開的網路流量，例如AWS EC2從Internet下載資料，就是Outbound。

AWS Security Group

在AWS中可以使用Security Group（安全群組）控制進出EC2的網路流量。 設定網站時，可以允許HTTP使用TCP Port 80進入伺服器，也可以允許HTTPS使用TCP Port 443進入伺服器。 若需要使用SSH遠端登入EC2，則可以使用Port 22，並將來源限制為自己的IP位址。

HTTP：TCP Port 80
HTTPS：TCP Port 443
SSH：TCP Port 22

例如網站的Inbound設定可以為HTTP、TCP、Port 80、Source為0.0.0.0/0， 代表允許所有IPv4位址透過HTTP連線到網站。

3. 什麼是CIDR

CIDR（Classless Inter-Domain Routing）是一種表示IP位址範圍的方法， 通常以「IP位址/數字」表示，例如192.168.1.0/24。

192.168.1.0/24

0.0.0.0/0代表所有IPv4位址，因此如果AWS Security Group的HTTP Port 80來源設定為0.0.0.0/0， 就代表所有IPv4位址都可以嘗試透過HTTP連線。

/32可以表示單一IPv4位址，例如192.168.1.100/32代表只有192.168.1.100這個IP位址。

0.0.0.0/0 → 所有IPv4位址
192.168.1.100/32 → 單一IPv4位址

4. 什麼是DNS？什麼是IP？什麼是網域名稱？什麼是URL？

IP

IP是網路設備在網路上的位址，用來讓資料知道要傳送到哪一台設備。

網域名稱

網域名稱（Domain Name）是方便使用者記憶的網站名稱，例如www.ncnu.edu.tw。

DNS

DNS（Domain Name System，網域名稱系統）主要負責將網域名稱解析成對應的IP位址。 例如使用者輸入www.ncnu.edu.tw後，DNS可以找到這個網域名稱所對應的IP位址。

網域名稱 → DNS → IP位址

URL

URL（Uniform Resource Locator）是用來表示網路資源位置的完整網址。

https://www.ncnu.edu.tw/1234/class/upload.php?file=abc

5. URL範例分析

以下為URL範例：

https://www.ncnu.edu.tw/1234/class/upload.php?file=abc

https:// 代表使用HTTPS協定。

www.ncnu.edu.tw 是網站的網域名稱或主機名稱。

/1234/class/upload.php 是網站中的路徑，用來指定要存取的資源。

?file=abc 是查詢參數，其中file是參數名稱，abc是參數值。

如果沒有另外指定Port，HTTPS預設使用Port 443。

因此這個URL代表使用HTTPS連線到www.ncnu.edu.tw， 存取/1234/class/upload.php這個路徑， 並傳送file=abc這個參數給伺服器。
